# LAST CIRCLE — 브라우저 배틀로얄

브라우저에서 바로 돌아가는 오리지널 3D 배틀로얄 게임입니다. (Three.js, 빌드 과정 없음)

- 수송기 낙하 → 파밍 → 줄어드는 자기장 → 최후의 1인/1팀
- 총기 12종, 조준경·소음기·손잡이·탄창 부착물, 헬멧·방탄복·배낭 1~3레벨
- 엎드리기, 장애물 넘기, 회복·부스트, 수류탄·연막탄, 보급 상자
- 듀오·스쿼드 기절/부활, 봇 최대 32명
- 방 코드 멀티플레이: 어디서 열든 동작 (claude.ai 안에서는 내장 room 기능, 그 밖에서는 WebRTC P2P 직접 연결)
- 모바일 터치 지원: 가상 조이스틱, 드래그로 시점, 발사·조준·점프·앉기·엎드리기 버튼
- 인벤토리 드래그 앤 드롭: 주변 ↔ 가방 ↔ 장비 ↔ 무기 칸 ↔ 부착물 칸

## 실행

정적 파일이라 아무 웹 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 멀티플레이

방장이 **방 만들기**를 누르면 5자리 코드가 나오고, 친구가 같은 주소에서 코드를 입력하면 들어옵니다.

- **GitHub Pages / 일반 웹 서버**: [Trystero](https://github.com/dmotz/trystero)로 브라우저끼리 WebRTC 직접 연결합니다. 별도 서버가 필요 없고, 서로를 찾을 때만 공개 Nostr 릴레이를 씁니다.
- **claude.ai 아티팩트**: 아티팩트 내장 `room` 기능을 씁니다.
- 일부 회사·학교 망이나 모바일 데이터망처럼 방화벽이 엄격한 곳에서는 P2P 연결이 안 될 수 있습니다 (TURN 서버를 붙이면 해결).

## 모바일

가로 화면 권장. 왼쪽 엄지로 조이스틱(끝까지 밀면 달리기), 오른쪽 화면을 끌어서 시점, 발사 버튼을 누른 채 끌면 조준하면서 사격합니다. 메뉴의 **전체화면** 버튼을 쓰면 더 편합니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD / Shift / Space | 이동 / 달리기 / 점프·넘기 |
| C / Z | 앉기 / 엎드리기 |
| 좌클릭 / 우클릭 | 사격 / 조준 |
| R / B | 재장전 / 사격 모드 |
| 1 2 3 4 5 | 주무기1·주무기2·권총·맨손·투척 |
| F | 줍기·낙하·낙하산·부활(길게) |
| Tab / M | 인벤토리 (끌어서 장착·교체·버리기) / 지도 |
| H, 7 8 9 0 - | 회복 아이템 |
| Q / E / V | 기울이기 / 1·3인칭 |

## 구조

`js/world.js` 섬·건물·식생 생성, `js/game.js` 경기·동기화, `js/player.js` 플레이어 조작, `js/bots.js` 봇 AI, `js/models.js` 캐릭터·총기 모델, `js/hud.js` UI·인벤토리, `js/net.js` 네트워크(room / P2P), `js/touch.js` 모바일 조작.

## 최근 업데이트
- 화면 끊김·시점 튐 수정 (마우스 급변 입력 필터, 셰이더 미리 컴파일, 풀 생성 분산, 해상도 조절 완화)
- 옥상 진입: 평지붕 건물은 마지막 계단이 옥상으로 이어지고, 창고는 외부 계단으로 지붕에 오를 수 있음 · 넘기 높이 2.65m
- 유리창: 통과 불가, 총알·주먹·수류탄·넘기로 한 번 깨짐 (멀티 동기화)
- 캐릭터 가시성: 림 라이트, 원거리 안개 감소, 밝은 옷 색
- 편의: 자동 줍기(탄약·회복·상위 장비, 설정에서 끄기), Shift+F / 인벤토리 버튼으로 주변 모두 줍기, `=` 자동 달리기, 조준 토글 옵션
- 건물 깜빡임(지지직) 수정: 창틀·유리·바닥이 겹치던 면 정리, 깊이 정밀도 2배 → 측정상 깜빡이는 픽셀 95% 감소
- 해상도 자동 조절 최저 80%로 (픽셀 깨짐 방지), 설정에서 끄기 가능
- 가늠자 조준: 뒤쪽 가늠쇠에 홈을 내서 화면 중앙이 보이도록, 레드닷 링 하우징·얇은 홀로 프레임
- 편의: Alt 자유 시점, 수류탄 궤적 미리보기, 총성·발소리 방향 표시, 근처 아이템 이름 표시(★ = 쓸만한 아이템)
