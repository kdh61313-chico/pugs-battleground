# LAST CIRCLE — 브라우저 배틀로얄

브라우저에서 바로 돌아가는 오리지널 3D 배틀로얄 게임입니다. (Three.js, 빌드 과정 없음)

- 수송기 낙하 → 파밍 → 줄어드는 자기장 → 최후의 1인/1팀
- 총기 12종, 조준경·소음기·손잡이·탄창 부착물, 헬멧·방탄복·배낭 1~3레벨
- 엎드리기, 장애물 넘기, 회복·부스트, 수류탄·연막탄, 보급 상자
- 듀오·스쿼드 기절/부활, 봇 최대 32명
- 방 코드 멀티플레이 (claude.ai 아티팩트의 `room` 기능 사용)

## 실행

정적 파일이라 아무 웹 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

> 멀티플레이(방 만들기/코드 입장)는 claude.ai 아티팩트 안에서만 동작합니다.
> 그 밖의 곳(GitHub Pages, 로컬 서버)에서는 **혼자 연습(봇전)** 모드로 플레이할 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD / Shift / Space | 이동 / 달리기 / 점프·넘기 |
| C / Z | 앉기 / 엎드리기 |
| 좌클릭 / 우클릭 | 사격 / 조준 |
| R / B | 재장전 / 사격 모드 |
| 1 2 3 4 5 | 주무기1·주무기2·권총·맨손·투척 |
| F | 줍기·낙하·낙하산·부활(길게) |
| Tab / M | 인벤토리 / 지도 |
| H, 7 8 9 0 - | 회복 아이템 |
| Q / E / V | 기울이기 / 1·3인칭 |

## 구조

`js/world.js` 섬·건물·식생 생성, `js/game.js` 경기·동기화, `js/player.js` 플레이어 조작, `js/bots.js` 봇 AI, `js/models.js` 캐릭터·총기 모델, `js/hud.js` UI.
